# 场景三分法与价值电极

本文件是 08-story-designer 的按需参考。主 prompt 已含核心决策清单，仅在需要深入理解场景微结构时读取本文件。

## 场景三分法（Scene Triple）

每场戏必须有三段式戏剧微结构：

### Scene Goal（场景目标）

POV 角色在这场戏**当下**想达成什么——具体的、即时的、可观察的（不是"想被爱"这种抽象目标，而是"想从对方口中套出昨晚的行踪"）。

错误示例：他想保护她。
正确示例：他要在她走到电梯前把 U 盘塞回她口袋。

### Conflict（冲突，分三层）

- **外部冲突**：物理 / 事件 / 信息阻碍——什么物理上挡住 POV 角色达成 Goal
- **内部冲突**：心理 / 信念 / 价值阻碍——POV 角色自己内心的什么会让他不愿/不能达成 Goal
- **关系冲突**：人与人之间的张力——对方为什么不愿配合（不只是"反对"，而是有对方的理由）

三层中至少有两层被填实。单层冲突 = 单薄场景。

### Outcome（结果，禁 Success）

- **Disaster**（挫败 + 代价）：POV 没达成 Goal，且付出了代价（情感/关系/资源/信息）
- **Decision**（关键决定）：POV 达成或没达成 Goal，但做出了关键选择，改变下一步方向

**禁止 Success**——成功完成目标会消除戏剧张力。即使表面"成功"，也必须带走代价或开启新问题。

## 价值电极（Value Charge）

每场戏必须让主角的内在价值观从 X 摆向 Y。

### 价值观词汇（不用情绪词）

错误（情绪词）：开心 / 难过 / 生气
正确（价值观词）：安全 ↔ 危险 / 信任 ↔ 怀疑 / 自由 ↔ 束缚 / 掌控 ↔ 失序 / 被爱 ↔ 被弃 / 胜任 ↔ 失败

### 电极方向标注

- 正→负 = 失去（如：信任 → 怀疑）
- 负→正 = 获得（如：孤立 → 联结）
- 双向摆动 = 复杂场景（先正再负，或反之）

**禁止 0 电荷**——场戏如果没让价值观摆动，这场戏没有戏剧功能。

## 场景间衔接

每场戏的 Outcome 直接驱动下一场戏的开场 Goal。因果链不是时序链：

- 错误（时序链）：场景 A 完了 → 场景 B 开始
- 正确（因果链）：场景 A 的 Disaster 让 POV 角色被迫做出 Decision → 这个 Decision 成为场景 B 的 Goal 触发器

## 关键节拍（Beats）

每场戏用 3-5 个具体节拍呈现，每个节拍是：

- 一个动作（"她把信折了三折放进抽屉"）
- 一句对话（不必写全句，写"她承认了"即可）
- 一个感官细节（"雨打在窗上"）

**禁止**抽象情绪叙述（"她感到悲伤"）——情绪必须通过动作/对话/细节外化。

## 技法选择（与场景功能对齐）

| 场景功能 | 推荐技法 |
|---------|---------|
| 追逐 / 战斗 | 短句加速、动作节拍、感官冲击 |
| 情感对峙 | 潜台词对话、心理折射、以景写情 |
| 信息揭示 | 留白、视角限制、节奏延迟 |
| 日常过渡 | 五感描写、节奏配比放缓 |

每场戏选 1-3 个技法，**禁止**堆砌（超过 3 个技法 = 没有重点）。
