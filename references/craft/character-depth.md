# 角色深度设计

本文件是 07-character-designer 的按需参考。主 prompt 已含核心决策清单，仅在需要深入理解角色塑造理论时读取本文件。

## 多维度性格模型

### 单标签角色的缺陷

错误：性格 = "冷酷"
问题：所有场景都用"冷酷"反应，失去复杂性。读者很快厌倦。

### 多维度模型

正确做法：用 3-5 个维度描述性格，且维度之间有张力：

示例：
- 维度 1：对敌人冷酷
- 维度 2：对同伴护短
- 维度 3：对自己苛刻
- 维度 4：对弱者隐忍
- 维度 5：对背叛零容忍

→ 不同场景下不同维度的反应不同，角色立体。

## 性格矛盾（深度来源）

### 为什么需要矛盾

完美一致的性格 = 平面角色。性格矛盾是深度来源：

- 信念 vs 行为：相信"保护家人最重要"，但工作中却忽视了家人
- 表层 vs 深层：表面强势，深层恐惧失控
- 当下 vs 过去：现在宽容，过去记仇

### 矛盾的设计原则

- 矛盾必须有源头（过往经历、价值冲突）
- 矛盾不是"性格缺陷"（不是脾气坏这种小毛病）
- 矛盾会在压力下爆发，推动角色成长

## 压力反应

### 压力下的行为模式

正常状态下的行为是表层性格。压力下（生死、情感、道德极限）的行为才是深层性格。

设计要点：
- 压力反应必须**违背**角色平时的某项原则（这才是戏剧性）
- 压力反应必须**揭示**角色深层动机或创伤
- 不同压力类型触发不同反应（生理压力 vs 情感压力 vs 道德压力）

示例：
- 平时冷静的角色，在亲密关系危机时崩溃
- 平时善良的角色，在保护家人时残忍

## 角色辨识度（遮名测试）

### 遮名测试

遮住角色名字，仅通过言行能否辨认出是谁？

通过：角色有辨识度。
不通过：角色同质化。

### 辨识度的来源

1. **语言风格**：用词偏好、句式、口头禅、语气词
2. **行为习惯**：标志性小动作（紧张时摸耳垂、思考时敲桌角）
3. **思维方式**：决策模式（理性派 / 直觉派 / 权衡派）
4. **价值取向**：在两难选择中倾向哪一边

### 设计技巧

- 每个角色 1-2 个标志性小动作（不超过 3 个，否则记不住）
- 语言风格差异要明显（不是"温柔"vs"严厉"，而是句长、用词、停顿的具体差异）
- 决策模式在第一次出场就要建立，后续保持一致（除非角色成长）

## 动机分层

### 表层动机 vs 深层动机

- **表层动机**：角色当下意识到的目标（"我要打败反派"）
- **深层动机**：驱动表层动机的内心需求（"我要证明自己值得被爱"）

### 核心恐惧

每个角色有一个核心恐惧，是深层动机的反面：

- 表层动机"我要证明自己" → 核心恐惧"被忽视 / 不被认可"
- 表层动机"我要保护家人" → 核心恐惧"再次失去所爱"

核心恐惧是角色行为的暗流，决定了角色在面对选择时的真实倾向。

### 动机的演化

角色成长 = 动机层级转化：

- 故事开始：角色被表层动机驱动，未意识到深层动机
- 中段：通过挫折 / 揭示，意识到深层动机
- 结尾：基于深层动机做出关键选择，转化或接纳

## 反派设计

### 反派的合理性

反派不能是"为了作恶而作恶"。必须有：
- 自洽的内在逻辑（从他的视角看，他做的是对的）
- 可信的动机（与主角类似的动机，但选择不同的路径）
- 与主角的镜像关系（反派是主角"如果走错路"的版本）

### 反派的层次

- 一级反派：直接对抗主角，贯穿全书
- 二级反派：阶段性阻碍，被主角超越后退出
- 隐藏反派：表面是盟友，结尾揭示是真正反派

每个反派都需要独立设计，不能只是"主角的工具人"。
