# 章首钩子与章末钩子设计

本文件是 08-story-designer 的按需参考。主 prompt 中已要求每章必须有章首 + 章末钩子，本文件展开四种类型的判定与具体设计。

## 章首钩子（4 类型）

### 1. 悬念钩（Suspense Hook）

用未解之谜开场，让读者带着问题进入。

设计要点：
- 抛出具体问题（不是抽象疑问）
- 不立即回答
- 问题与本章核心事件相关

示例：开篇一句对话"你信不信，我会亲手杀了他"，不交代说话人、对象、场合——制造双重悬念（谁说？杀谁？）。

### 2. 场景钩（Scene Hook）

用强烈的感官画面开场，让读者直接被环境抓住。

设计要点：
- 具体、独特的场景元素（不是"清晨阳光明媚"这种泛景）
- 至少 2 种感官（视觉 + 听觉 / 嗅觉 / 触觉）
- 场景本身预示本章氛围

示例：开篇写雨打在窗棂上的声音、远处寺钟的尾音、桌上凉透的茶——三个感官元素叠加，预示压抑氛围。

### 3. 情感钩（Emotional Hook）

用 POV 角色的强烈内心状态开场。

设计要点：
- 通过外在行为暗示内心（不是直白叙述）
- 情感状态具体而非泛指
- 暗示前史（让读者好奇"为什么这样"）

示例：开篇主角把一封信读了又折、折了又读、最后烧掉——通过动作暗示执念与决绝。

### 4. 行动钩（Action Hook）

用 POV 角色正在进行的动作开场，制造动态感。

设计要点：
- 动作正在进行中（不是"准备做"）
- 动作本身有危险性或紧迫感
- 动作的目的暂不交代

示例：开篇主角正在撬锁——目的、身份、危险程度都暂不交代，制造紧迫感与好奇心。

## 章末钩子（4 类型）

### 1. 未完结悬念（Cliffhanger）

事件正在发生，结果未定。

示例：主角推开房门，看到本不该出现的人——结尾停在手停在门把手上那一刻。

### 2. 情感未决（Emotional Unresolved）

情感冲突未被解决，留下张力。

示例：两人吵了一架，谁也没道歉，主角关灯躺下，听见对方也还没睡——结尾停在这沉默里。

### 3. 反转（Twist）

揭示一个颠覆既有认知的事实。

示例：结尾主角发现一直以为是敌人的那个人，其实是暗中保护自己的人。

### 4. 留白（Ellipsis）

事件告一段落，但暗示更大的下一波。

示例：主角解决了一个小问题，结尾看着窗外，远处有辆陌生的车停了一夜——暗示新威胁正在到来。

## 钩子设计禁忌

### 禁忌 1：泛指钩子

错误："开头要吸引读者注意" / "结尾要留悬念"
正确：必须写明用什么具体手法、什么具体场景/对话/动作

### 禁忌 2：与本章无关的钩子

钩子必须与本章核心事件相关。不能为了"开头吸引人"硬塞一个与本章无关的悬念。

### 禁忌 3：章首钩子和章末钩子类型重复

除非有意形成结构呼应，否则章首和章末应使用不同类型的钩子，避免节奏单调。

### 禁忌 4：钩子被立即解决

章首钩子不能在章首就被解答（除非引出更大的新钩子）；章末钩子不能在章末被解决（必须留给下一章）。
